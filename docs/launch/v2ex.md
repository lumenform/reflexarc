# V2EX「分享创造」发布稿

**标题**：做了只不聊天、不调大模型的桌宠：它会累、会晕、会怕你熬夜——把两个开源项目焊在了一起

---

桌宠这个东西，要么是跟随鼠标播片，要么是点一下调 LLM 聊天（慢、贵、还出戏）。都是「演」，不是「活」。

我先说结果——它现在住在我电脑里：
- 我打字，它跟着一起忙；我把 CPU 压满，它先晕过去
- 鼠标靠近它，它会**转头看你**（16 个方向的眼神跟随）
- 摸它一下，头顶冒爱心；**按住能把它拎起来**，它会蹬腿、看着鼠标晃，松手会掉下去摔晕
- 双击它会弹一个极简状态气泡：`♥` 想被摸 / `Z` 困了 / `?` 无聊
- 它有自己的**五维性格**（好奇/粘人/懒/抗压/夜猫子），随机开局，然后被你的作息慢慢塑形——连续熬夜一周，它真会变成夜猫子

全程没有一句对话，没调一次大模型。

**原料（GitHub 组装）：**
- **petdex**：4800+ 只动画桌宠素材库，开放精灵图格式
- **laya**：非自回归「System 1」决策引擎，单次前向出结果，不生成文本

**焊出来的东西（ReflexArc / 反射弧）：**

给桌宠装上一条真正的反射弧：
- **感官**：键盘/鼠标闲置时长、CPU 负载、电量、时间段、前台窗口的「类别」（只看类别，不存标题）
- **内稳态**：精力、无聊度、情绪、依恋、压力、社交饥渴——六个慢变量一直自己在演化
- **决策**：确定性「本能」（微秒级，随时在线）+ laya「直觉」（后台每 8 秒刷新，给行为打分，权重混合）
- **身体**：轻量物理（走路有加减速、跳跃有弧线、落地有挤压）、呼吸起伏、随机小动作（伸懒腰/瞥一眼/摆尾巴）、4 段水獭音效

**顺路实测的两个结论（给想用 laya 的人排雷）：**
1. multilingual 检查点零样本在这个任务上**完全不可用**——4 个差异巨大的场景它 4 次全选「开心地跳」。官方文档说它只是个待特化的基座，实测确认。
2. **typed-decisions** 检查点零样本就能用：深夜「睡觉」得分 0.54，工作时只有 0.10。没有 GPU 也没关系——48 个合成场景做 z-score 校准（约 40 行代码），把基线的偏置去掉、留下条件信号。

Python 写的，MIT 开源。素材运行时从 petdex 拉取（社区作品，不打包进仓库）。
