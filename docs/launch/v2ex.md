# V2EX / 掘金 / 即时 草稿

**标题：** 我把两个 GitHub 项目焊在一起，做了个不聊天但「会活」的桌宠

---

桌宠这个东西，要么是跟随鼠标播片（BongoCat 那种），要么是点一下调 LLM 聊天（慢、贵、还出戏）。都是「演」，不是「活」。

这次我拿 GitHub 上两个新项目焊了个怪东西：

**原料：**
- **petdex**：4875 只动画桌宠素材库，开放精灵图格式
- **laya**：非自回归「System 1」决策引擎，单次前向出结果，不生成文本

**焊出来的东西（ReflexArc / 反射弧）：**

给桌宠装上一条真正的反射弧：
- **感官**：键盘/鼠标闲置时长、CPU 负载、电量、时间段、前台窗口的「类别」（只看类别，不存标题）
- **内稳态**：精力、无聊度、情绪、依恋、压力、社交饥渴——六个慢变量一直自己在演化
- **行为**：每几秒做一次决策，在两个层面上：确定性「本能」（微秒级，随时在线）+ laya「直觉」（后台每 8 秒刷新，给你的行为打分）

**所以它会有这些反应（实测跑了一天的场景模拟）：**
- 你在深夜 23:30 还在肝 → 它困得不行但还是守在旁边看你
- 你打字打得飞起 → 它跟着你一起「忙」
- 你刷视频 → 它趴着安静看你
- 你 CPU 飙到 97% → 它比你晕得还快
- 你走开俩小时 → 先自己踱步，然后睡觉，偶尔跑出来对你招手

**它不聊天。** 没有对话，没有 prompt。整个东西是「养」出来的：它有个五维性格（好奇/粘人/懒/抗压/夜猫子），随机开局，然后**被你作息慢慢塑形**——你熬夜一周，它就真变成夜猫子。

**顺路实测到的两个结论（给想用 laya 的人排雷）：**
1. laya 的 multilingual 零样本在这个任务上**完全不可用**——我给 4 个差异巨大的场景，它 4 次全选「开心地跳」。官方文档说它只是个待特化的基座，实测确认。
2. **typed-decisions** 检查点零样本就能用：深夜「睡觉」得分 0.54，工作时只有 0.10；CPU 97% 时「崩溃」得分 0.45，基线 0.25 左右。没有 GPU 也没关系——我写了 48 个合成场景的校准（z-score 去偏置），40 行代码完成「穷人特化」。

Python 写的，MIT 开源，约 2000 行。素材运行时从 petdex 拉取（社区作品，不打包进仓库）。
