# 抖音/小红书 短视频脚本（30-40 秒）

## 备选标题
- 「我给电脑养了只宠物，它靠你的键盘声活着」
- 「它不聊天，但它活着」
- 「桌宠进化了：这次真的住里了」
- 「程序员桌面右下角的东西，有点吓人」

## 分镜脚本（约 38 秒）

**[0-4s] 钩子**
画面：桌面右下角，一只小水獭本来在发呆（idle），你一打字，它立刻站起来跟着「忙」（mirror-work）
字幕：「你打字的时候，它在加班」
画外/配音：你的桌宠会跟着你一起忙，这事不奇怪——奇怪的是，它这不是动画。

**[4-12s] 三个反差场景（快切）**
1. 深夜 23:40 的场景 → 水獭打哈欠、眼皮耷拉（rest），字幕：「凌晨了你还在卷，它困得眼睛都睁不开，但没走」
2. CPU 跑程序飙红 → 水獭头晕目眩（overwhelmed），字幕：「你的 CPU 一炸，它比你先晕」
3. 你离开两小时回来 → 水獭在屏幕中间招手（waving），字幕：「你走了俩小时，它出来找你」

**[12-22s] 揭秘**
字幕 + 画面（架构示意图）：「它不聊天、没接大模型。它有一条反射弧。」
画外：键盘声、CPU、电量、时间——这些都是它的「感官」。它体内有六个一直在变的量：精力、无聊、情绪、依恋、压力、社交。它每一秒都在自己决定要干什么。
字幕：「另一套大脑负责『直觉』——一个不生成文字、单次推断的决策引擎。」

**[22-30s] 养成点**
画面：早晨的宠物 vs 深夜的宠物（不同精神状态）
字幕：「性格随机生成，会被你养出来——你熬夜一周，它就变成夜猫子」
画外：它不是「设置」出来的，是养出来的。

**[30-38s] 结尾 + 行动**
字幕：「开源，免费，MIT。GitHub 搜 ReflexArc」
画外：评论区置顶要链接 → 引导互动（「想看它还有什么本能？评论区点菜」）

## 置顶评论
项目完全开源（GitHub：ReflexArc）。素材来自 petdex 社区 4875 只宠物，运行时自动下载。Python 写的，会写代码的可以自己魔改性格和行为。

## 拍摄注意
- 录屏要真机录（不要用演示 GIF，真实感更重要）
- 深夜场景建议真在 23 点后录，显示系统时间更有说服力
- 打字声 + 轻 BGM，节奏点可以卡在状态切换瞬间
