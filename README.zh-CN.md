# ReflexArc 反射弧

[English](README.md) | 中文

**你的桌宠不是下载的，是养大的。**

它不聊天、不调大模型，只是**活着**：你深夜打字它陪着忙，你 CPU 压满它比你先晕，
你离开太久它出来招手——而且它会慢慢变成夜猫子，因为你就是。
ReflexArc 给它装的不是脚本，是一条真正的**反射弧**。

```
  感官                  神经中枢                    效应器
+-------------+      +---------------------+      +----------------------+
| 键鼠闲置时长 |      | 内稳态驱动：         |      | 16 方向注视（眼神）   |
| CPU 负载    | ---> | 精力 无聊 情绪       | ---> | 呼吸 / 影子 / 情绪符号 |
| 电量        |      | 依恋 压力 社交饥渴   |      | 物理（走跑跳 / 被抓）  |
| 时间段      |      |         +           |      | petdex 精灵动画       |
| 前台窗口类别 |      | 决策 = 本能 + 直觉   |      | 透明、鼠标穿透、      |
| 光标位置    |      +---------------------+      | 置顶的小窗口          |
+-------------+               |                  +----------------------+
                              v
                     性格随作息缓慢漂移
                     （夜猫子、粘人、懒……）
```

它不聊天。它只是**活着**：凌晨一点会困、无聊时自己踱步、你深度工作时陪着你忙、你离开太久会出来招手、你 CPU 飙红它比你先晕。

## 它怎么"活"起来

大多数桌宠是"会播动画的贴纸"。ReflexArc 让它活，靠的是七层叠在一起的东西：

1. **会看着你**。petdex v2 图集里藏着 16 个视线方向帧——绝大多数播放器只用了前 9 行。
   ReflexArc 把它们全部用起来：你鼠标靠近，它盯着鼠标看（**转头是逐档转过去的**，
   半圈 0.35 秒，不是瞬间朝跳）；你切窗口，它转向你的窗口方向；闲着时视线自己慢慢游移；
   困了头会垂下去。
2. **会呼吸、有影子**。静止时有呼吸起伏（频率随精力和性格变化，睡觉时又慢又深），
   脚下有软影子——跳起来时影子留在地上、变小变淡，落地才回来。
3. **有物理**。走路有起步-巡航-刹车，不再是匀速滑块；开心时原地小跳（起跳预蹲 →
   腾空 → 落地压扁回弹，带一两次余震）。
4. **可以被抓起来**。伸手按住它就能拎走（它会蹬腿、盯着你的手看），松手自由落体。
   轻轻放下它心情变好；摔重了它会晕头转向、掉眼泪。桌面照常点击——它只在
   你**停在它身上**的那一瞬间接管鼠标，其他地方永远穿透。
5. **会表达**。困了头顶飘 `Zzz`，被摸冒 `♥`，CPU 烧起来先冒汗、再发抖、最后晕倒——
   而且**情绪长在身上**：开心时会小幅弹跳，摔疼了会缩成一团微微发抖，无聊时会慢慢晃悠。
   它还有一套轻量水獭音效（被摸"嘤～"、被拎起"唧！"、摔疼"呜…"），默认开启、很轻，
   `REFLEXARC_SOUND=0` 可关。
6. **能读懂它**。**双击它**，头顶会弹出一个极简状态气泡——`♥` 想被摸、`Z` 困了、
   `…` 无聊、`💧` 压力大、`⌣` 心情不错。不用猜它在想什么。
7. **有小动作**。长时间发呆时它会左右张望、深呼吸、伸懒腰、小跳一下——频率由性格决定：
   懒的宠物安安静静，好奇的宠物东张西望。
8. **有身体记忆**。被抓过、被摔过、被摸过都会留下来：次数记进档案，摔重了真的会
   影响心情和压力值。

## 由两个开源项目组装

- **[petdex](https://github.com/crafter-station/petdex)** —— 4800+ 只社区动画宠物、开放的精灵图格式。ReflexArc 拿它当**身体**：运行时从 petdex 目录拉取宠物，也会自动读取你本地的 `~/.petdex/pets`、`~/.codex/pets`。宠物素材版权归各作者，不打包进本仓库。
- **[laya](https://github.com/NandhaKishorM/laya)** —— 非自回归「System 1」决策引擎（单次前向、不生成文本）。可选，扮演宠物的**直觉**：给行为打分，小权重混合进决策。

## 两层决策

1. **本能层**——永远在线、确定性、微秒级。用效用函数给九种候选行为打分（结合内稳态和感官）。这是脊椎：可解释、可预测、永不死机。
2. **直觉层**——可选。laya 对处境回答八个独立的是/否问题（「现在该睡觉吗？」「该找你吗？」），答案经过校准后以小权重混入。laya 缺席、慢了、答错了，宠物照样靠本能活着。

### 实测笔记：不花 GPU 把一个基座模型用起来

- **multilingual 检查点零样本完全不可用**：四个差异巨大的场景（凌晨疲惫 / 深度工作 / 独处 / CPU 97%）它全选「开心地跳」。官方文档说得对——laya 是「待特化的快速基座」，不是现成决策器。
- **typed-decisions 检查点零样本就能用**：深夜「睡觉」0.54 对工作时 0.10；CPU 97% 时「崩溃」0.45 对基线 0.25；「陪你忙」专注工作时 0.61-0.67 对空闲时 0.22。
- **不做微调也能特化**：微调要 2×T4 跑几小时。`calibrate_intuition.py` 用 48 个合成场景测出每个问题的基线（均值/方差），线上答案做 z-score 校准——模型的条件信号留下，全局偏置干掉。约 40 行代码。
- **速度**：CPU 上八问一批约 3.5 秒（首次含加载约 25 秒）。放进游戏循环没戏，所以直觉层跑在后台线程、每 8 秒刷新一次、只当「轻推」不当「神谕」。

## 实测行为谱

来自 `tests/scenario.py`（同一天里快进模拟）：

| 情境 | 行为 |
| --- | --- |
| 安静的早晨，人在旁边但没互动 | 踱步 194+193 次、发呆 182 次、偶尔找你 19 次 |
| 深度工作、狂敲键盘 | 陪你忙 664 次，偶尔鼓掌 14 次 |
| 下午倦怠 | 望天 290 次、踱步若干、偶尔雀跃 |
| 晚上一起看视频 | 趴着看你 187 次 |
| 23:30 还在肝 | 守着你 254 次，偶尔跟着忙 39 次 |
| CPU 飙到 97% | 晕头转向 230 次（风扇还没叫，它先慌了） |
| 被晾了几个小时 | 踱步 245+245 次、睡觉 60 次、时不时招手找你 14 次 |

行为会「自我满足」（走路会消解无聊、找人能缓解社交饥渴），所以没有哪种动作会无限重复。
行为持续时长由性格缩放——懒的宠物发呆更久，好奇的宠物走得更勤。

## 它感知什么（隐私优先）

| 信号 | 用途 | 是否存储 |
| --- | --- | --- |
| 键鼠闲置时长 | 活跃度 / 无聊 | 仅聚合值 |
| CPU 负载 | 压力 / 崩溃反应 | 内存中平滑值 |
| 电量 | 对「累了的电脑」共情 | 内存中 |
| 时间段 | 作息节律 / 夜猫子漂移 | 内存中 |
| 前台窗口**类别** | 观察 / 沉思 / 望向 | 只存类别——标题永不存储、永不发送 |
| 光标位置 | 眼神跟随 / 抚摸 / 抓取 | 不存储 |

一切不出本机。性格、驱动力和历史存在 `~/.reflexarc/state.json`。

## 会被养出来的性格

五个维度：好奇、粘人、懒、抗压、夜猫子。首次运行随机生成，然后随着你的真实作息**缓慢漂移**——你熬夜一周，它就真变夜猫子。不是设置项，是结果。
性格还决定它**看起来多忙**：懒的宠物安安静静、久久发呆；好奇的宠物张望频繁、小动作不断。

## 快速开始

```bash
# 核心引擎，零依赖（无界面）
python run.py --headless --duration 30 --fresh

# 桌面宠物：透明、鼠标穿透、置顶
pip install PySide6 psutil
python run.py --scale 1.25

# 可选的直觉层
pip install "laya[onnx]"          # 或 pip install laya
python calibrate_intuition.py --model-dir models/laya-typed \
    --model-key typed-decisions --out state/calibration.json --n 48
python run.py --scale 1.25        # 自动探测直觉层
python run.py --no-laya           # 或者在不需要时关闭
```

怎么玩：**鼠标靠近**它会看你；**悬停到它身上**会慢慢摸它（头顶冒心）；**点击**是一下抚摸；
**双击**问它现在想要什么（头顶弹状态气泡）；**按住拖走**可以把它拎起来（松手会掉下去——
轻放和摔重它反应不一样，摔很了会冒星星晕过去）；**托盘图标**可以暂停或退出。

首次运行会自动从 petdex 目录拉取宠物（`--pet-slug boba`，4800+ 任选）。直觉层的模型权重由 laya 自行下载（HuggingFace `convaiinnovations/laya`）。

## 命令行与环境变量

```
python run.py [--headless] [--duration N] [--fresh] [--seed N]
              [--name NAME] [--pet-slug SLUG] [--scale F] [--no-laya]
```

| 环境变量 | 作用 |
| --- | --- |
| `REFLEXARC_NO_GRAB=1` | 关闭「抓起来」交互（窗口永远完全穿透，只保留悬停/点击抚摸） |
| `REFLEXARC_SOUND=0` | 静音（默认开启，音效很轻） |
| `REFLEXARC_BREATH=0` | 关闭呼吸起伏 |
| `REFLEXARC_EMOTES=0` | 关闭情绪符号（Zzz / ♥ / 汗滴） |
| `REFLEXARC_DEBUG_HUD=1` | 每 2 秒打印帧耗时（tick/paint），并做一次穿透自检 |
| `REFLEXARC_FORCE_X/Y` | 强制窗口位置（调试/多屏用） |

## 测试

```bash
python -m tests.gaze_math        # 注视数学（方向映射/转向速度/迟滞）
python -m tests.motion_physics   # 物理（加减速/跳跃弧/落地压缩/拖拽）
python -m tests.scenario         # 一整天快进行为模拟
python -m tests.integration 90   # 真实时钟端到端（含 laya）
python -m tests.look_probe       # 校验新宠物图集的 16 方向约定（需 Pillow）
```

前三个零依赖、可进 CI。换新宠物素材后建议跑一次 `look_probe`——方向约定不符时它会翻车（看向反方向），脚本会提前告诉你。
