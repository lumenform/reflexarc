# ReflexArc 反射弧

**给桌宠装上一套神经系统。**

现在的桌宠要么播循环动画，要么你戳一下它才调一次大模型——都像死的。ReflexArc 换了个思路：给它一条真正的**反射弧**。

```
  感官                  神经中枢                    效应器
+-------------+      +---------------------+      +------------------+
| 键鼠闲置时长 |      | 内稳态驱动：         |      | petdex 精灵动画  |
| CPU 负载    | ---> | 精力 无聊 情绪       | ---> | idle / 走路 /    |
| 电量        |      | 依恋 压力 社交饥渴   |      | 招手 / 跳跃 /    |
| 时间段      |      |         +           |      | 崩溃 / 等待 /    |
| 前台窗口类别 |      | 决策 = 本能 + 直觉   |      | 忙碌 / 沉思      |
+-------------+      +---------------------+      +------------------+
                              |                    透明、鼠标穿透、
                              v                    置顶的小窗口
                     性格随作息缓慢漂移
                     （夜猫子、粘人、懒……）
```

它不聊天。它只是**活着**：凌晨一点会困、无聊时自己踱步、你深度工作时陪着你忙、你离开太久会出来招手、你 CPU 飙红它比你先晕。

## 由两个开源项目组装

- **[petdex](https://github.com/crafter-station/petdex)** —— 4800+ 只社区动画宠物、开放的精灵图格式。ReflexArc 拿它当**身体**：运行时从 petdex 目录拉取宠物，也会自动读取你本地的 `~/.petdex/pets`、`~/.codex/pets`。宠物素材版权归各作者，不打包进本仓库。
- **[laya](https://github.com/NandhaKishorM/laya)** —— 非自回归「System 1」决策引擎（单次前向、不生成文本）。可选，扮演宠物的**直觉**：给行为打分，小权重混合进决策。

## 两层决策

1. **本能层**——永远在线、确定性、微秒级。用效用函数给九种候选行为打分（结合内稳态和感官）。这是脊椎：可解释、可预测、永不死机。
2. **直觉层**——可选。laya 对处境回答八个独立的是/否问题（「现在该睡觉吗？」「该找你吗？」），答案经过校准后以小权重混入。laya 缺席、慢了、答错了，宠物照样靠本能活着。

### 实测笔记：不花 GPU 把一个基座模型用起来

- **multilingual 检查点零样本完全不可用**：四个差异巨大的场景（凌晨疲惫 / 深度工作 / 独处 / CPU 97%）它全选「开心地跳」。官方文档说得对——laya 是「待特化的快速基座」，不是现成决策器。
- **typed-decisions 检查点零样本就能用**：深夜「睡觉」0.54 对工作时 0.10；CPU 97% 时「崩溃」0.45 对基线 0.25；「陪你忙」专注工作时 0.61-0.67 对空闲时 0.22。
- **不做微调也能特化**：微调要 2×T4 跑几小时。`calibrate_intuition.py` 用 48 个合成场景测出每个问题的基线（均值/方差），线上答案做 z-score 校准——模型的条件信号留下，全局偏置干掉。约 40 行代码。
- **速度**：CPU 上八问一批约 3.5 秒（首次含加载约 25 秒）。放进游戏循环没戏，所以直觉层跑在后台线程、每 8 秒刷新一次、只当「轻推」不当「神谕」。

## 实测行为谱

来自 `tests/scenario.py`（同一天里快进模拟）：

| 情境 | 行为 |
| --- | --- |
| 安静的早晨，人在旁边但没互动 | 发呆 228 次 + 踱步 278 次 + 偶尔找你 22 次 |
| 深度工作、狂敲键盘 | 陪你忙 575 次，偶尔鼓掌 |
| 下午倦怠 | 望天 355 次、踱步若干、偶尔雀跃 |
| 晚上一起看视频 | 趴着看你 220 次 |
| 23:30 还在肝 | 守着你 281 次，偶尔跟着忙 61 次 |
| CPU 飙到 97% | 晕头转向 106 次 × 硬撑着陪你 87 次 |
| 被晾了几个小时 | 踱步 361 次、睡觉 71 次、时不时招手找你 15 次 |

行为会「自我满足」（走路会消解无聊、找人能缓解社交饥渴），所以没有哪种动作会无限重复。

## 它感知什么（隐私优先）

| 信号 | 用途 | 是否存储 |
| --- | --- | --- |
| 键鼠闲置时长 | 活跃度 / 无聊 | 仅聚合值 |
| CPU 负载 | 压力 / 崩溃反应 | 内存中平滑值 |
| 电量 | 对「累了的电脑」共情 | 内存中 |
| 时间段 | 作息节律 / 夜猫子漂移 | 内存中 |
| 前台窗口**类别** | 观察 / 沉思 | 只存类别——标题永不存储、永不发送 |

一切不出本机。性格、驱动力和历史存在 `~/.reflexarc/state.json`。

## 会被养出来的性格

五个维度：好奇、粘人、懒、抗压、夜猫子。首次运行随机生成，然后随着你的真实作息**缓慢漂移**——你熬夜一周，它就真变夜猫子。不是设置项，是结果。

## 快速开始

```bash
# 核心引擎，零依赖（无界面）
python run.py --headless --duration 30 --fresh

# 桌面宠物：透明、鼠标穿透、置顶
pip install PySide6 psutil
python run.py --scale 1.25

# 可选的直觉层
pip install "laya[onnx]"          # 或 pip install laya
python calibrate_intuition.py --model-dir models/laya-typed \
    --model-key typed-decisions --out state/calibration.json --n 48
python run.py --scale 1.25        # 自动探测直觉层
python run.py --no-laya           # 或者在不需要时关闭
```

首次运行会自动从 petdex 目录拉取宠物（`--pet-slug boba`，4800+ 任选）。直觉层的模型权重由 laya 自行下载（HuggingFace `convaiinnovations/laya`）。

## 命令行

```
python run.py [--headless] [--duration N] [--fresh] [--seed N]
              [--name NAME] [--pet-slug SLUG] [--scale F] [--no-laya]
```
